# Java Practice Programs

Welcome to my Java repository! This is a personal space where I type up, test, and save standalone Java programs from my notebook to build my logic and programming skills.

## 📂 Repository Contents
This repository contains a collection of individual Java files covering:
* Core logic and syntax practice
* Mathematical and arithmetic programs
* Pattern printing and loop exercises

## 🚀 How to Run
1. Open this project folder in **VS Code**.
2. Open any `.java` file.
3. Click the **Run** (Play) button in the top-right corner of the editor.

* **Language:** Java
